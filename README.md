# Landing Page

A simple landing page built as part of **The Odin Project** Foundations course.

The main goal of this project was to practice building a webpage from scratch using HTML and CSS, with a focus on **Flexbox** and structuring a page into reusable sections.

## Preview

https://its-manos.github.io/landing-page/

## Built With

* HTML5
* CSS3
* Flexbox

## What I Practiced

* Structuring a webpage with semantic HTML
* Using Flexbox for page layouts
* Aligning and spacing elements with Flexbox
* Creating responsive layouts
* Working with images and captions
* Styling buttons, links, and navigation
* Using CSS classes to organize styles
* Working with viewport units such as `vh`
* Using `flex`, `gap`, `padding`, and `margin` for layout control

## Sections

The page includes:

* Header with navigation links
* Hero section with an image and call-to-action button
* Random information section
* Quote section
* Call-to-action section
* Footer

This project helped me get more comfortable with Flexbox, especially understanding how `flex`, `justify-content`, `align-items`, and sizing interact with each other.

I also got some practice making sure content doesn't overflow when the browser window changes size.
